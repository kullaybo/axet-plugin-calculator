# aXet Calculator

Calculator application developed for the aXet.plugin for Developers Learning Activity.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Division-by-zero handling
- Calculation history
- Calculation timestamps
- Clear calculation history
- Clear calculator

## Technology

- HTML
- CSS
- JavaScript
- Visual Studio Code
- aXet.plugin

## aXet.plugin Usage

aXet.plugin was used to:

- analyse the original calculator;
- identify refactoring opportunities;
- implement operation history;
- improve separation of concerns;
- improve input validation;
- improve error handling;
- review the final implementation.

## Run Locally

Open:

index.html

in a web browser.
